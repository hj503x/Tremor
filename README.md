# TREMOR — US Macro Event Reference

A standalone, single-file reference tool for how US economic data releases
and Fed events typically move markets — built for quick lookup before or
during a trade, not for live data.

## What it does

- Every major US macro event (CPI, NFP, PPI, PCE, FOMC, ISM, JOLTS,
  housing data, and more) organized by category
- Each event's typical "hot vs. cold" market reaction — how USD, Treasury
  yields, and stocks tend to move on a better- or worse-than-expected print
- Impact tier (Very High / High / Medium / Low) with a quick visual signal
- Which instruments (DXY, EURUSD, XAUUSD, US10Y, SPX, BTCUSD) react
  hardest to each release, with tap-to-view definitions
- Typical release timing relative to the London/NY liquidity overlap
- "Read alongside" notes — which companion release changes how a print
  should be interpreted (e.g. NFP + wage growth)
- A compare mode to view 2–3 events side by side
- Deep links to a specific event (`#cpi-core-cpi`) for bookmarking

## What it isn't

No live data feed, no API, no backend. This is deliberately static —
market reactions here describe typical, historically consistent patterns,
not real-time forecasts, actuals, or a guarantee of any single release's
outcome. Edit the data directly in the file to keep it current.

## Usage

Open `tremor-reference.html` directly in a browser, or host it via
GitHub Pages for a shareable link and "Add to Home Screen" support on
mobile.
